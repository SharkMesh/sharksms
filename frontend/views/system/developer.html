开发者模式 API 说明文档

欢迎使用 灭世SMS 开放接口。本接口专为第三方开发者设计，支持高度自动化的下单流程与任务控制逻辑。

1. 基础信息

• 接口域名: 联系管理员获取

• 数据格式: application/json

• 请求方式: 统一使用 POST

安全提示： 所有接口请求必须配置 IP 白名单 且通过 MD5 签名校验 方可调用。
2. 签名算法 (Signature)

为确保数据完整性及请求来源可靠，所有 API 请求必须包含 sign 字段。

计算步骤：

1. 提取参数：获取除 sign 外的所有 POST 参数。

2. 升序排序：按参数名 ASCII 码升序排列。

3. 拼接串流：格式如 key1=val1&key2=val2...。

4. 追加密钥：在串流末尾直接追加您的 api_key。

5. MD5 摘要：执行 32 位小写 MD5 加密，生成 sign。

Node.js Implementation Example 
const crypto = require('crypto');

const body = {
  api_secret: "as_xxxxxxxxxxxx",
  phone: "13800138000",
  duration: "10"
};
const apiKey = "ak_xxxxxxxxxxxx"; // 后台安全中心获取

// 1. 字典序排序并拼接
const signStr = Object.keys(body).sort().map(k => `${k}=${body[k]}`).join('&') + apiKey;

// 2. MD5 加密 (32位小写)
const sign = crypto.createHash('md5').update(signStr).digest('hex');

// 3. 最终请求体
body.sign = sign;
3.1 请求下单 (Place Order)

发起一个新的短信压力测试或通知任务。

POST /api/open/task/create

参数 类型 必填 说明
api_secret String YES API 通讯密钥
phone String YES 目标手机号
duration String YES 任务时长 (分)
sign String YES 签名
Success Response
{
  "code": 200,
  "msg": "下单成功",
  "data": { "task_id": 12345 },
  "timestamp": "2026-08-17 23:50:00"
}
3.2 请求中止 (Stop Order)

即时停止目标任务的运行状态。

POST /api/open/task/stop

参数 类型 必填 说明
api_secret String YES API 通讯密钥
task_id Number YES 唯一任务 ID
sign String YES 签名
3.3 获取用户信息 (Get User Info)

获取当前 API 账号的积分余额及基本资料。

POST /api/open/user/info

参数 类型 必填 说明
api_secret String YES API 通讯密钥
sign String YES 数据摘要签名
Success Response
{
  "code": 200,
  "msg": "获取成功",
  "data": {
    "username": "example_user",
    "points": 1000,
    "money": 50.00
  },
  "timestamp": "2026-08-18 16:00:00"
}
4. 常见错误码
状态码 含义 排查方案
400 参数缺失 请核对必填参数项，特别是 sign 字段
401 鉴权失败 检查 api_key 追加位置或 api_secret 是否正确
403 受限操作 IP 不在白名单或账号状态异常（封禁）
500 业务限制 手机号已在任务列表或积分账户余额不足
